# Desafio Power BI — DIO

## 📊 Sobre o projeto

Projeto desenvolvido durante o desafio de Power BI da DIO, com o objetivo de aplicar conceitos de análise de dados e criação de visualizações utilizando o Power BI.

O projeto utiliza uma base de dados disponibilizada durante o curso e apresenta informações relacionadas a vendas, unidades vendidas, lucro e segmentos.

## 🎯 Objetivos

* Reproduzir as páginas desenvolvidas durante o curso;
* Criar uma terceira página de análise de dados;
* Desenvolver mapas utilizando dados de vendas e lucro por país;
* Criar um gráfico de pizza para análise de lucro por segmento;
* Aplicar boas práticas de organização e apresentação dos visuais;
* Desenvolver familiaridade com o Power BI e GitHub.
